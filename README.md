# PE1

## If you are on a different computer and need to get the code from GitHub, do the following:

Open your terminal, navigate to where you want the folder to live (e.g., `D:` and then `cd D:\School`), and clone it:
  git clone https://github.com/SireOfTheQuags/PE1.git
  *(This creates a `PE1` folder right inside your current directory.)*

## To commit changes to the GitHub page, perform the following commands in Command Prompt in the PE1 folder:
1. git add .

2. git commit -m "Describe what you changed or added"

3. git push
