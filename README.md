# PE1

## Cloning on a New or Lab Computer
If you are setting up on a different machine and need to pull the repository:
1. Open your terminal and navigate to the target directory (e.g., `D:` and then `cd D:\School`). Inside this directory a folder 'PE1' will be created.
2. Run the clone command:
   git clone https://github.com/SireOfTheQuags/PE1.git

## Daily Commit & Push Workflow
To save and sync your work, double-click the `push.bat` file inside your `PE1` folder, type your commit message when prompted, and press Enter.
